# temaEstacionamento

nome do projeto: Descansador de carros

integrantes da equipe: Ruan Gabriel Benatti e Rodrigo Camargo de Oliveira

Tema escolhido: Estacionamento

Objetivo do sistema: Um sistema onde os funcinarios podem ter controle dos carros estacionados, e os clientes podem reservar vagas

Tecnologias que serão ultilizadas: MySQL, C#

Descrição: Usuario loga, se identifica como cliente ou funcionario, logo apos faz sua reserva, se for cliente e se for funcionario, faz o cadastro da reserva

Requisitos funcionais: Cadastro de cliente, cadastro de vagas, Cadastro de funcionario, Cadastro de carro, reserva de vaga(funcionario ou cliente), Determinação de tempo, pagamento da reserva(cliente), edição de usuario(cliente e funcionario), Calcular o valor da permanência, Exibir quantidade de vagas disponíveis, edição do carro.

Requisitos nao funcionais: Interface moderna e eficiente, Manutenibilidade, Confiabilidade, Desempenho, Disponibilidade

Principal publico: Pessoas qu4e precisam de um estacionamento, donos de estacionamento
